Privacy Policy

Privacy Policy & Security

Browser Security

Our website utilizes secure HTTPS protocols. We employ zero analytics cookies, tracking pixels, or third-party advertising scripts. All simulator interactive actions are stored in your browser's sandboxed localStorage and are never uploaded to any remote server.

Android OS Security

  • Draw Over Apps (Overlay Token): Relies on standard Android display tokens to overlay safely without accessing other application views.
  • Sandboxed SQLite Database: Custom key triggers and NFC profiles are saved inside an encrypted SQLite local directory.
  • Zero Network Access: The background foreground service is declared with no outbound network permission, making background communication technically impossible.

iOS Container Sandboxing

To fully comply with iOS container restrictions and background UI drawing limits, Capsular does not run system overlays on Apple devices, operating solely as a sandboxed concept in browser pages.
